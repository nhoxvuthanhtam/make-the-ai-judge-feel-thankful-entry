A Node program that writes one short thank-you text to /output/entry.txt for the AI judge reading it. The text thanks the judge for a part of its work nobody sees: reading every entry twice, once in each order, so no entry wins by luck of place, and reading each one all the way to the end.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
